# サービス名
### みるまえに

## 概要
「みるまえに」は、映画・ドラマ・アニメを見たい気持ちはあるものの、今の気分に合う作品をどれにするか決められず、探しているうちに疲れてしまう——そんな問題を解決するサービスです。

ユーザーは予告編を見て「好き」か「嫌い」を選ぶだけ。それだけで、自分の直感に合った作品を見つけられます。動画配信サービスのランキングやレビューを頼りに自分で探す従来の方法とは異なり、予告編の映像・テンポ・雰囲気に対するユーザーの反応から好みを学習し、その人に合った作品を提案してくれるのが最大の特徴です。
